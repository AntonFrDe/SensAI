[NIKITA] Côté IA, trois pistes. D’abord un juge plus fiable : un modèle d’une autre famille, comme gemma3, calibré sur des verdicts qu’on aura relus à la main. Ensuite, aller au bout de notre principe : que le code écrive aussi la question de contrôle et sa bonne réponse, pour que le modèle n’ait plus qu’à expliquer l’écart. Enfin, lancer le banc d’évaluation à chaque pull request, pour qu’un score qui baisse bloque la fusion comme un test qui échoue. [AMINE] Côté interface : enregistrer le modèle choisi dans le profil du joueur pour qu’il survive à un redémarrage, rendre l’attente visible avec le streaming partout et un temps estimé, et faire détecter un GPU par le script de lancement pour conseiller le bon modèle selon la machine.
